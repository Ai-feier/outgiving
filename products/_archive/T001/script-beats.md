总时长：~75s | 平台：抖音 9:16 | 弧线：经典弧

- **[ANTAGONIST] Yhwach** 外观统一：黑色披风+多瞳眼睛+灵王之杖（可变条件：Almighty 发动时瞳孔分裂特效+空间碎裂)
- **[SHINIGAMI_CAPTAINS]** 统一：队长羽织+各人斩魄刀特征（可变条件：卍解状态追加武器/身体变化）
- **[SIDEKICK] Rukia** 外观统一：黑色短发+死霸装+袖白雪（复用 DEMO 规格，待复检 IaD）
- **[STERNITTER]** 群体外观：白色完圣体光翼+光环（可变条件：个体差异仅剪影区分，不要求精确身份识别）

**空间/环境级**
- 尸魂界/瀞灵廷：白色传统建筑群+高对比天空（可变条件：侵蚀前完整状态 vs 侵蚀后废墟焦痕）
- 一护内心觉醒空间：纯黑背景+橙色灵力脉络/光升腾
- 决战高空空间：混沌黑白碎片+灵力粒子悬浮
- 色彩基调：中低明度黑白基底，#E8760B 橙色唯一强调色
- 主光源方向：无定向高对比（Bleach 标志性 flat lighting+rim light）
- 材质语言：高对比黑白+锐利线稿。暗部深蓝黑，亮部冷白

**叙事级**
- 视角：第三人称客观视角，全片不切主观镜头（B9 Almighty 为角色能力展示，非主观 POV）
- 时间框架：非线性浓缩——入侵→集结→觉醒→决战的跨时空剪辑
- 主题意象：力量对抗命运、绝望到希望、握刀者永不屈服
- 音频基调：史诗管弦+战斗交响。D 骤降处瞬寂/基底抽离
- 负面材质排除：禁止 3D 渲染效果、禁止实拍纹理、禁止柔光模糊/雾化

**运动/镜头级**
- 运镜语法：快速剪辑+慢镜收束交替。Bleach 标志性的速度线和静止对比
- 元素动效风格：灵力=橙色粒子+速度线拖尾；破坏=黑色碎片+墨渍状扩散
- 景深策略：浅景深突出角色（B5/B7/B11），广角展现场景破坏（B1/B3/B10b）
- 慢动作使用：仅用于关键定格瞬间——B4 余烬坠落、B5b 觉醒抬头、B8 尾帧收束、B10c 跪地余韵

**材质/色调级**
- 色调板全局映射：monochromatic + 橙色强调 (#E8760B)
- 线稿规范：锐利肯定有速度感，外轮廓强调。静止场景线条收细（久保带人风格）
- 强调色使用门禁：橙色 (#E8760B) 仅用于一护灵压/月牙天冲。完圣体=冷白。卍解火焰=暖橘偏红（非标准橙）

## 叙事弧线概述

经典弧线。从宁静被打破到压倒性绝望——友哈巴赫率领星十字骑士团入侵尸魂界，护廷十三队卍解迎战后留下的只有废墟。情绪跌至最低点（战后余烬，3秒黑屏）。转折点从一护的双刀觉醒开始——他在内心世界同时握住虚与死神的力量，头生虚角，希望重新点燃。力量展示和伙伴集结后发起冲锋，抵达全片情绪峰值。但友哈巴赫的全知全能（Almighty）瞬间颠覆局势——空间定格、能量吞噬、冲锋被锁定在半空。最终在宿命对决中走向壮绝的高潮（月牙天冲全功率 vs 灵子攻击）与余韵（一护跪地喘息）。全片是一条从「被命运碾压」到「握刀对抗命运」的情绪旅程。

情绪关键词序列：不安 → 压倒 → 绝望 → 悲壮 → 沉寂 → 觉醒 → 亢奋 → 团结 → 冲锋 → 逆转 → 壮绝 → 余韵。峰值 5/5（B8 冲锋 / B10 决战）。

#### Beat 2：灭却师之王 [6s]
