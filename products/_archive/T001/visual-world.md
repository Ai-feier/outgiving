# 死神祸进篇 — 视觉宪法

> 千年血战 PV，抖音 9:16 竖屏。风格锚定：久保带人视觉哲学。
> 对应 `topics/T001/visual-assets-spec.md`（资产规格）。基于 `styles/bleach.md` 六维推导。
> 工具：Seedance 2.0（火山引擎 ARK）。参考策略：每角色 ≤3 张 + 场景 ≤1 张 + 总 ≤4 槽。

---

## 1. 视觉形态

**类型**：角色叙事 PV（P0=角色面部+身份锚点）。Bleach 千年血战篇预告风格。
**风格**：Bleach / 久保带人 — 高反差黑白美学 + 剪影优先 + 三色法色指定。
**平台**：抖音。前 3 秒视觉钩子（Yhwach 压倒性存在或一护双刀觉醒），后续节奏按三段式战斗呼吸。
**时间**：60-90s。

**核心视觉矛盾**：
- 死神（黑+白+银） vs 灭却师（纯白+蓝） — 色彩阵营对立
- 日常都市 → 超自然战场 — 场景错位
- 一护单刀 → 双刀 — 身份完整性的视觉表达

## 2. 六维 + V 定义

### 2.1 镜头 [STYLE-DEP: bleach]

| 焦距 | 语义 | 场景 |
|------|------|------|
| 24mm（广角） | 沉浸/渺小 | 尸魂界宽景、Yhwach 力量展示、废墟全景 |
| 50mm（中性） | 对峙/对话 | 角色对峙、斩魄刀解放前、台词时刻 |
| 85mm（长焦） | 窥视/不安/亲密 | 多瞳特写、情绪蓄力、刀尖反光 |


### 2.2 运镜 [STYLE-DEP: bleach]

**语汇（≤3 种）**：
1. **Static** — 对峙宽景，1.5-3s 蓄力。镜头绝对静止，画面内仅有微动（衣角/散发）
2. **Snap Zoom / Push** — 斩击/解放/力量爆发时瞬移推进。0.3-0.8s 内完成。
3. **Slow Pan** — 空间建立，水平/垂直 ≤2s。仅用于场景首次出现或情绪过渡。

**禁止**：快速旋转 / whip pan / complex tracking / crane / 溶解过渡 / 淡入淡出。
**过渡**：硬切（hard cut）唯一允许。Bleach 的三段式（对峙→交锋→余波）全部用硬切连接。

### 2.3 布光 [STYLE-DEP: bleach]

| 参数 | 值 |
|------|----|
| 主光 | 侧逆光 135°，角色面部 40% 阴影覆盖 |
| 对比度 | 高。暗部压至 #060810，亮部不过曝 #E8F0F8。中间调最少 |
| 色温 | 亮部冷白 #E8F0F8 / 暗部深蓝黑 #0A0E1A / 暖调仅在火光/能力爆发时出现 |
| 边缘光 | 背光场景角色边缘 1-2px 冷白 rim light（日系透过光） |
| 能力光 | 色相偏移阴影：月牙天冲时阴影偏橙、虚闪时偏紫、灵子光时偏蓝 |

**光逻辑**：情绪优先。光照不遵循物理光源逻辑——服务于角色内心状态。

### 2.5 构图 [STYLE-DEP: bleach]

| 类型 | 用法 | 视线路径 |
|------|------|---------|
| 三分法 | 对话/对峙 | 角色视线引导，左→右 |
| 中心 | 力量展示/解放 | 放射线汇聚至角色中心点 |
| 负空间 | 力量差/孤绝 | 角色极小（画面 15-25%），大量留白/留黑 |

**规则**：
- 左→右：日常/空座町（Bleach 日常语法）
- 右→左：尸魂界/无形帝国/紧张场景（紧张语法）
- 目线引导剪接：角色视线方向 = 下一拍焦点
- 每 cut ≤2 焦点，超过后观众迷失
- 剪影优先：无需面部即知角色身份（发型/武器/站姿剪影）

### 2.6 景深与焦点 [STYLE-DEP: bleach]

**语法**：撮影処理的ぼかし（空气透视 + 径向模糊），非物理镜头 DOF。

| 技术 | 用法 |
|------|------|
| 速度线（スピード線） | 瞬移/斩击时使用。密集平行线指示运动方向。密度=速度 |
| 径向模糊 | 情绪特写时背景柔化（前景清晰，背景呈放射状模糊） |
| 空气透视 | 远景饱和度 -30%，叠加环境色淡出层 |
| 深焦 | 对峙宽景，全画面清晰 |

**禁止**：真实镜头的色散、暗角、畸变、柔焦、过渡曝光。

### 2.7 V 定义（视觉复杂度）

| Beat 类型 | V | 条件 |
|-----------|---|------|
| 战斗瞬移/斩击 | 2-3 | 1-2主体 + 简洁背景 + 能量特效 |
| 对峙/蓄力 | 2 | 1-2主体 + 负空间/纯色背景 |
| 宽景展示 | 3-4 | 场景破坏 + 群体 + 多材质（≤5材质类） |
| 情绪特写 | 1 | 单主体 + 纯色背景 |

**V×CF<4 约束**：CF 由 rhythm-designer 独立标定。V≥4 时 CF 须 ≤3。

## 3. 情绪动作化

### 抽象词 → 身体锚点（千年血战专用）

| 情绪 | 角色 | 禁用词 | 身体锚点 | 类型 | 标记动作 |
|------|------|--------|---------|------|---------|
| 坚定 | 一护 | determined | jaw set, shoulders squared, locked gaze, steady controlled breathing on exhale | 压抑→爆发 | 刀尖缓缓转向敌人 |
| 愤怒 | 一护 | angry | fists clenched on sword handle, chest heaving, eyes fixed forward, teeth gritted on inhale | 压抑→爆发 | 双刀交叉蓄力至释放点 |
| 恐惧 | 死神众 | scared | body recoiling, eyes wide with visible sclera, hands trembling in front of chest, frozen stance | 瞬间爆发 | 后退半步 → 僵直 |
| 威压 | 友哈巴赫 | powerful | standing upright, relaxed shoulders, slight upturn of lips, eyes scanning slowly, one hand in coat | 压抑型 | 多瞳同时缓慢转动 |
| 绝望 | 山本/总队长 | despair | head lowered, shoulders dropped, sword point touching or scraping ground, labored breathing | 压抑型 | 刀尖插地 = 身体支撑 |
| 惊讶 | 旁观角色 | shocked | eyebrows raised, eyes wide, mouth partially open, breath caught mid-inhale, body pulls back | 瞬间爆发 | 身体后仰 |

### 文化差异补充
- **止め絵静止蓄力**：战斗前全身僵持 + 微颤（非不动，是即将动的边缘状态）。1-2s 停顿让观众感知"下一刻发生什么"
- **無言沉默**：Bleach 台词后必留沉默。沉默长度正比于上一句的重量。重要台词后 1.5-3s 沉默
- **身体第一**：身体锚点优先于面部表情（IaD/DESformer 验证：身体泄露真实情绪，无需面部）
- **三通道独立**：面部=身份（中性参考图）/ 身体=情绪（锚点控制）/ 3D偏移场=表情（提示词控制）

## 5. 光线质感

### 场景光环境

| 场景 | 光类型 | 色温 | 氛围 |
|------|--------|------|------|
| 空座町 | 低角度夕阳，斜射长影 | 暖橙 #E8A050 | 日常被入侵前最后温暖 |
| 尸魂界（战后） | 漫射天光，无明确主光源 | 淡白蓝 #C0D0E0 | 静谧被打破的痕迹 |
| 战斗废墟 | 火光动态照明 + 烟尘散射 | 橙红 #D05020 + 阴影黑 | 混乱 + 绝望 |
| 无形帝国 | 冷荧光（灵子光自发光） | 蓝 #4060C0 | 非自然 + 压迫 |
| Wahrwelt | 极寒散射（无自然光） | 冰蓝 #80B8D0 | 孤绝 + 最终舞台 |

### 高对比处理规则
- 阴影区：全黑或深蓝黑 #060810，不保留细节。"黑就是黑。"
- 亮部区：冷白溢出 #E8F0F8，不保留细节。"白就是白。"
- 中间调：减少，仅保留在角色面部颧骨/鼻梁过渡区

### Seedance 参考图策略

- 角色：1 帧复合图（正面+半侧+全身合一，中性表情）+ 多视角分布图（分别入不同槽）
- 场景：≥1 帧定调图
- 总参考图 ≤4 张 + 运镜视频 1 段 + 音频 1 段
- Reference Lock 模板：
  ```
  Use the uploaded character image as the visual anchor. Preserve: [face, hairstyle, outfit, age, sword type]. Do not change: [clothing, facial structure, hair color, proportions]. Style: Bleach anime, cel shading, sharp lines, high contrast.
  ```
- @ 标记：每参考图显式分配角色（`@Image1 as Ichigo front-face reference`）

### 实体复现间隔

| 类型 | 约束 |
|------|------|
| 主角（一护） | ≤3 拍内必须复现 |
| 配角（友哈巴赫、露琪亚） | ≤5 拍 |

## 8. 视觉DNA + 资源分配

### 视觉DNA表

| 要素 | Bleach 定义 | 约束 |
|------|-----------|------|
| 线稿 | 锐利肯定，外轮廓强调。战斗变粗飞白，静止收细 | 禁止矢量完美线 |

## 9. 排除设计

### 全局禁止进 prompt（≤10 词）
```
no photorealism, no soft focus, no dissolve transitions, no warm glow filters, no continuous fight choreography, no lens effects
```

### 逐项说明

| 禁止项 | 理由 | 替代方案 |
|--------|------|---------|
| 柔焦 | Bleach 禁止 | 径向模糊（撮影処理的ぼかし） |
| 过渡曝光 | 高对比风格不允许亮部让步 | 冷白溢出 #E8F0F8 |
| 暖调滤镜 | 灭却师篇色彩回归冷调 | 色相偏移阴影 |
| 粉色/糖果色 | 不符合久保美学 | 低饱和基调 |
| 连续打斗 | Bleach 三段式呼吸 | 静止→瞬移→静止 |
| 溶解过渡 | Bleach 全篇硬切 | 硬切 only |
| 镜头色散/暗角 | 日系动画禁止物理镜头效果 | 撮影処理非物理模糊 |
| 照片级写实 | 风格帧必须保留动画感 | cel shading + 线稿 |
| 3D 渲染感 | 破坏日系 2D 美学 | 统一线稿 + 三色法 |
| 角色背景同线宽 | 角色无法从背景浮出 | 角色线粗 40% |
| 全局 LUT 调色 | 每材质类须独立色指定 | 三色法独立指定 |
