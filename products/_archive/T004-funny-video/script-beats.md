## 情感弧线总览

```
能量
  ^
  |  [Hook]           [Ch2: 五阶段]          [Ending]
  |   /派对高潮\            / 高潮 \            / 温暖 \
  |  /          \   [Ch1] /  喜剧  \  [Ch3]  /       \
  | /            \  /   /  顶峰    \  /  泪点 \  /    \
  |/              \/   /            \/  山谷   \/      \
  +-------------------------------------------------------> 时间
```

**结构**: 前 3 章递进 (笑→更笑→安静→哭→笑回去)，最后送温暖。
**秘密武器**: 第 3 章（5:30-8:00）是整片灵魂——前半有多好笑，后半就有多动人。
