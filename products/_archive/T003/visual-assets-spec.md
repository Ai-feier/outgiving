## 2. 角色参考图规格

### 2.1 Yhwach — 规范参考

**目标文件**：`CHR_T003_bleach_Yhwach_canonical_v01.png`

**角色描述**：

- 体格：宽肩高大，年长男性。非修长型——Bleach 中少数体宽压倒性的角色
- 面部：深眼窝、浓密胡须（从耳际到下颌连接）、眉毛粗重且略上挑、鼻梁高直
- 眼睛：红瞳（#CC2233）——虹膜为红色，非发光状态。多重瞳孔结构（外圈深红→内圈亮红渐变）。这是 T003 最核心的视觉锚点
- 发型：长黑发（接近肩线），向后梳理，两侧鬓角及肩
- 服装：纯白灭却师服（白色长外套+黑色内衬+深蓝披风）。领口直立。胸口有十字架纹样（金色）。黑色紧身手套到肘部
- 标志物：无武器——Yhwach 不持刀，戴黑色手套的双手即武器

**IaD 要求（中性表情）**：

- 面部：零表情。嘴自然闭合，嘴唇无明显线条。眼睑半闭（N/3 开度）。瞳孔平视前方。
- 身体：直立，双臂自然垂于体侧或双手交握置于身前（王座姿势）。肩线水平。
- 三通道：面部=身份（中性）、身体=情绪（克制的绝对静止）、3D偏移场=待编辑

**构图组合帧要求（KeyFrame-Compass ≤1 帧复合）**：

```
左 1/3: 正面肖像（头部至胸部，中性表情，平视镜头）
中 1/3: 半侧 3/4 面（显示面部立体感+胡须厚度+眼窝深度）
右 1/3: 全身站姿（显示纯白灭却师服+十字架纹样+裁缝比例）
```

**生成约束**：

- 分辨率：短边 ≥1024px，建议 1536×2048（3:4 竖幅）
- 格式：.png，无背景（透明底方便组合帧）或黑底
- 光照：侧顶光（45 度左上），暗部深蓝黑 10% 亮度。冷白 rim light
- 禁止：微笑、愤怒表情、武器、正面平光（破坏高对比度）

### 2.2 Ichigo True Shikai — 规范参考

**目标文件**：`CHR_T003_bleach_IchigoTS_canonical_v01.png`

**角色描述**：

- 体格：修长瘦削，宽肩窄腰，少年→青年过渡期体型
- 面部：锐利下颌线，细长眼睛（眼尾上挑），棱角分明鼻梁。嘴型窄薄。
- 眼睛：棕色虹膜。日常状态水平直视或略低垂。
- 发型：橙色刺状发束（非规则尖刺——束形有厚薄变化，每束末端尖锐）。前额 4-5 束上扬，两侧鬓角 2-3 束外翘。头发是剪影辨识度的核心。
- 服装：黑色死霸装——宽袖口+宽裤口，腰间无刀鞘（双刀形态无鞘）。黑色腰带系于腰间。足穿草履+脚踝白带。
- **双刀（最重要特征）**：
  - **长刀（右手握=死神之力）**：长度约 120cm（角色身高的 2/3）。刀身银白色。刀柄为紫色卍字纹缠绕（「卍」字在图纹边缘隐约可见）。刀镡（护手）为不规则五边形，黑色。
  - **短刀（左手握=虚之力）**：长度约 50cm（长刀的 1/2）。刀身银白但边缘不规则——"被啃咬过的刀刃"（虚的破坏性）。刀柄黑色无缠绕。刀镡极小或无护手。
  - **双刀位置关系**：长刀在右（画面左侧）、短刀在左（画面右侧）。双刀交叉成 X 形置于胸前时为标志性姿势。

**IaD 要求（中性表情）**：

- 面部：嘴角微抿（不上扬不下沉——一护的默认防御表情）。眼神略低垂（不直视镜头，看向左下方 15 度）。
- 身体：直立，双肩水平。双臂弯曲（前臂与上臂成 90 度——自然持刀位）。双刀交叉置于胸前（X 形）。双手掌心向内。
- 三通道：面部=身份（中性微抿）、身体=情绪（克制的待命感）、3D偏移场=待编辑

**构图组合帧要求（KeyFrame-Compass ≤1 帧复合）**：

```
左 1/3: 正面肖像（头部到胸部，中性微抿表情，略低垂视线）
中 1/3: 半侧 3/4 面（显示双刀关系+发束立体感+死霸装褶皱）
右 1/3: 全身站姿（显示双刀+死霸装比例+双刀交叉X形姿势）
```

**生成约束**：

- 分辨率：短边 ≥1024px，建议 1536×2048（3:4 竖幅）
- 格式：.png，黑底
- 光照：侧逆光（右后 45 度），暗部深蓝黑 15% 亮度。刀身冷白高光为画面最亮部位。
- 禁止：微笑/大笑、单手持刀、刀鞘装备、Bankai（天锁斩月/ Horn of Salvation）、灵压特效（规范参考不要灵力发光）

## 3. 场景定调图规格

### 3.1 无形帝国冰宫（Hook 背景）

**目标文件**：`SCN_T003_bleach_Wandenreich_canonical_v01.png`

**视觉描述**：

- 环境：纯白冰宫结构（不是自然冰——是"灵子构成的纯白建筑"）。尖顶、多柱、几何化。光线从建筑内透出，非自然阳光。
- 天空：深蓝灰 #1A2A3A 到 #2A3A4A 渐变。无云无月——空的天空。
- 氛围：冷（色温 7000K+）。部分结霜。寂静。军队的影子投射在冰面上。

**构图**：

- 全景：画面 2/3 为冰宫建筑（居中略偏下），1/3 为天空
- 前景可有星十字骑士团剪影（作为远景点缀，非主角视角）

### 3.2 瀞灵廷（Escalation 背景 — 裂开前）

**目标文件**：`SCN_T003_bleach_SoulSociety_canonical_v01.png`

**视觉描述**：

- 环境：江户/明治传统木造建筑（入母屋造）。白色墙面+灰黑瓦顶。石板路。低层建筑为主（1-2 层）。
- 天空：黑到深蓝渐变（无云）。远处有不规则发光轮廓。
- 色调：基调黑+白+灰。墙面反射冷光。
- 关键特征：画面底层建筑需有适合被"横断裂开"的结构。裂开前是完整的。

**构图**：

- 中景：街道 + 两侧建筑 + 远景门楼
- 水平线在画面 1/3 处（天空留白 2/3——Bleach 风格的负空间）
