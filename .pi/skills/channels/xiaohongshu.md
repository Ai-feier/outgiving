## 写法法则

- **人格**：不是种草博主（替品牌说话），不是科普博主（教她做事），是"经历过、踩过坑、正在想"的朋友。**帮她审，不是帮她选。** 敢说边界、敢说不适合；展示过程，不只是结果。
- **搜索优先**：每篇先回答"她搜什么词会找到我"——标题含搜索长尾表达，自然场景化胜过堆砌。
- **证据链思维**：封面承诺什么，正文就证明什么；每篇是她信任链里的一块拼图，要能在 AI 搜索摘要截断前说清"为什么可信"。
- **标题与封面**：大字报式封面——浅色底 + 大标题 + 一个核心数字；实用抓人 > 精致含蓄；封面党失效（不一致即降权）。数字型标题最安全，纯问句会被摘要截断。
- **三种骨架选一**：干货型（冲突 → 具体错误当故事 → 方法论 2–3 条 → 反模式 → 行动）· 故事型（画面 → 时间线 → 转折 → 结论 → 行动）· 对比型（结果 → AB 测试 → 关键差异 2–4 维 → 选择建议 → 行动）。
- **一篇一个生态位**：搜索占位（默认）/ 圈层渗透 / 电商转化 / 品牌自证，单篇只占一个，同产品可多条线并行。
- **评论是第二内容生命线**：很多用户先看评论再看正文；发布后主号尽早发补充评论，埋关键词、引导讨论方向；争议点三法——观点前置 / 未完成思考 / 选择题法。
