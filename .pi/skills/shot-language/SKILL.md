# 镜头语言

给一个画面意图，选出这一拍用什么景别、什么运镜、什么角度、什么光。词汇表在 [`vocabulary.md`](vocabulary.md)——本文件写怎么选、怎么合。

## 每拍必达三要素

每拍至少指定 **景别**（定框架）+ **运镜**（定运动）+ **角度**（定情绪）。三者缺一，生成模型自由发挥的空间过大。光影与转场按需标注。

## 怎么选

1. 从**这一拍要让观众看什么 / 不看什么**出发，不选"好看"的词。
   - 缩小取景 = 命令观众聚焦（推近 = "请注意这里"）；取宽 = 让环境说话（极远景 = "这不重要"或"这太无力"）。
2. 三要素相互约束，改一个要重审其余：特写 + 低角度 = 压迫；特写 + 高角度 = 无力。
3. 运镜：单拍一种主导运镜。复合运动拆时序——`Start: slow dolly-in. Then: gentle pan right for final 2s`。速度只用 slow / medium / fast。
4. 光影：不写情绪词（"cinematic"/"moody"对模型无意义），写具体光照条件——用 vocabulary.md 的「光照-情绪速查」把情绪翻译成光。
5. 转场：默认硬切；只有需要"时间流逝"才用溶解。

## 与节奏的接口

切频与运镜强度由节奏决定——强度到运镜/景别的映射在 [`../rhythm/SKILL.md`](../rhythm/SKILL.md)「节奏-运镜耦合」。本 skill 负责选词，节奏负责强度与切频。工具对每种运镜的支持状态见 [`../prompt-engineering/tools.md`](../prompt-engineering/tools.md)。

## 例子

输入（骨架表一行）：

> 拍 3 · 4s · 画面「鲸鱼娘端着白米饭走上高台，抬头看见 Astra 娘一动不动」· 情绪「仰慕里的不情愿」

输出（镜头语言）：

> `景别: MCU`（胸上，保住"米"与"人"两个主体在同一框架）+ `运镜: slow dolly-in`（靠近 = 观众想看清那尊"不动的大佛"）+ `角度: slight low angle`（微仰，把高台上的主角抬高半档）+ `光影: warm practical lamp + soft fill`（高台的暖光只照亮供品，人物半在暗处）。
> 复合运动不需要：单拍一种主导运镜。转场到下一拍用硬切（同空间内递进，不需要溶解）。
