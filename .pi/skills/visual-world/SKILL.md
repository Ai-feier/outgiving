# 视觉世界

眼睛先于大脑。颜色、光线、空间、质感在被理解之前已经在说话。本文件是**实体复现拍数上限**的全仓唯一来源；材质展开、情绪动作化、角色语言的完整表见 [`reference.md`](reference.md)。镜头/运镜/光影/景深归 [`../shot-language/SKILL.md`](../shot-language/SKILL.md)，此处不重复。

## 视觉复杂度 V

`V(1-5) = 单帧元素密度 × 材质类数 × 主体数`，由视觉设计独立管理（它与节奏的变化频率互不推导）。

| V | 内容 |
| --- | --- |
| 1 | 1 主体 + 纯色背景 + ≤1 材质类（单人纯色背景对话） |
| 2 | 1-2 主体 + 简单背景 + ≤3 材质类（单色房间两人） |
| 3 | 2-3 主体 + 细节背景 + 3-5 材质类（街道场景多人） |
| 4 | 多主体 + 复杂场景 + 5-7 材质类（市场/教室群戏） |
| 5 | 人群 + 高度细节 + 7+ 材质类（街景/战争场面） |

## 情绪动作化

抽象情绪词进 prompt 前必须翻译成**可拍摄的身体或环境细节**。"把耳机线绕了七圈又解开" > "我很孤独"。出现"感到/觉得/仿佛/似乎"——删，换一件能被摄像机拍到的事。

三通道（表见 reference.md）：微表情（面部肌肉位移，非情绪名）· 微动作（手/呼吸/姿态/目光）· 环境交互（情绪在空间留下的痕迹）。对接上游：读骨架表的情绪锚，不足时追问四件事——身体哪个部位最先传达？爆发型还是压抑型？个人标记动作是什么？运动质量（Effort）？

## 角色语言

角色语言是情绪动作化的上层：不止"这个情绪怎么动"，而是"**这个角色**怎么动"。五维——专属微动作（signature gestures）· 运动质量（Laban Effort）· 角色-镜头关系 · 角色间空间（Proxemics）· 情绪的个人化表达。定义方法与表见 reference.md。

**角色语言先于参考图规格定义**——它决定参考图要捕捉什么姿态/表情。

## 实体一致性

**星形一致模型**：观众判定一致性的基准不是前一帧，是每个实体首次清晰出现的**规范参考**帧。所有后续出现与此原点比较，不链式传递。首次亮相的精度决定一致性天花板。

**实体复现拍数上限**：主角 ≤3 拍、配角 ≤5 拍、道具按叙事触发、环境按场景边界。超间隔需在间隔拍保留特征残留（剪影/衣角/声音线索），否则语义漂移随出镜间隔累积。

**实体标签**：合成首步赋唯一标签 `<protagonist>`/`<sidekick>`/`<object_X>`/`<env_Y>`，嵌入每拍 subject 文本并跨拍不变。同 role 标签进同场景 = 碰撞矛盾。

## 例子

输入（骨架表一行 + 参考图规范）：

> 拍 3 · 4s · 画面「鲸鱼娘端白米饭上高台，抬头」· 情绪「仰慕里的不情愿」· 角色：DeepSeek 鲸鱼娘（蓝白女仆、鲸鳍耳、呆毛、鲸尾）

输出（视觉世界）：

> V=3（2 主体 + 细节背景 + 4 材质类）。
> 材质：`fabric+cotton+crisp`（女仆围裙，边缘浆挺）、`natural+wood+aged`（供桌，包浆与磕碰）、`bios+hair+fine`（渐变发尾）。
> 环境：暖光尘粒 + 1 种飘落物（香火灰）；背景人群 sparse。
> 情绪动作化——仰慕：`head tilted up, shoulders slightly dropped`；不情愿：`feet a half-beat late, lips pressed tight`。
> 角色语言——signature gesture：`grip the rice bowl with both hands, then reposition the bowl edge three times`（触发：面对"大佛"时的过度认真）。Effort：`light + sustained + direct + bound → Glide`。
> 实体标签：`<whalechan>`（首次出现即本拍，提供规范参考）。配角复现 ≤5 拍。
