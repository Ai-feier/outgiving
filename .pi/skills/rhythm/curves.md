# 节奏曲线

## 10 条曲线类型

| 类型 | 特征 | 适合 | 不适合 |
| --- | --- | --- | --- |
| 匀速 | 等间距节拍 | 教程/列表/氛围 | 情绪递进内容 |
| 压缩-释放 | 紧张积累→突然释放 | 悬念/反转/震撼结论 | 平缓叙述 |
| 渐进加速 | 节拍越来越短 | "失控感"叙述 | 沉思内容 |
| 渐进减速 | 节拍越来越长 | 抒情/反思/升华 | 紧迫感内容 |
| 呼吸脉冲 | 紧→松→紧→松 周期性交替 | 30-60s 短片 | 纯信息型 |
| 空白即节拍 | 沉默/黑屏是主节奏 | 震撼时刻/金句后 | 信息密集型 |
| 断裂 | 意外中断后重启 | 转场/反转/形式突破 | 沉浸叙述 |
| 渐入渐出 | 慢→快→慢 | 故事型首尾 | 中间段 |
| 复节奏 | 画面切≠文字弹≠音频拍 | 数据叙事/艺术表达 | 单一信息内容 |
| 顿音 | 每拍 0.5-1.2s + 拍间沉默 | 喜剧/强反转/清单冲击 | 连续沉浸 |

曲线类型定义时间维度的变化形状；映射模式（同频/半速/倍速/反拍/对位/混沌）定义音画关系，见 [`SKILL.md`](SKILL.md)「音画节拍映射」。对位归入映射模式。

## 曲线 × 运镜适配

| 曲线类型 | 高能段运镜 | 低能段运镜 | 原则 |
| --- | --- | --- | --- |
| 压缩-释放 | handheld + dolly-in 积累 → 释放瞬间定格/whip pan | 释放后 static hold 2-3s | 积累期运动随紧张升维，释放期运动归零反差 |
| 呼吸脉冲 | 紧段：handheld 或 dolly-in 推进 | 松段：static 或 slow pull-back | 吸对应推进，呼对应松弛 |
| 顿音 | 拍段：quick push-in / 快速切 | 拍间：freeze frame / 静态 hold | 拍与沉默的极端对比也体现在运镜 |
| 渐入渐出 | 渐入：static→slow dolly→medium | 渐出：slow pull-back→static | 运镜加速度随曲线同步变化 |
| 空白即节拍 | 非沉默期：正常运镜 | 沉默期：static hold / 极微 push-in | 沉默时镜头几乎不动 |
| 断裂 | 断裂前：正常运镜 | 断裂：freeze/黑屏 → 重启：新运镜 pattern | 断裂是运镜节奏的突然归零 |
| 复节奏 | 主导流运镜快，次级流慢 | — | 各节奏层运镜速度不同，产生复调 |
| 匀速/渐进加速/渐进减速 | 按 SKILL.md 通用强度映射 | 按 SKILL.md 通用强度映射 | 无特殊特化 |

## 护栏

- **One verb per shot**：单拍只一种主导运镜。复合运动拆时序。
- **速度标量**：统一 slow / medium / fast。
- **节奏-运镜不一致优先纠偏**：高强节奏配 static → 观众感知为"意外停顿"（可故意用于悬念）。非故意 → 加运镜或调切频。

运镜词汇与定义见 [`../shot-language/vocabulary.md`](../shot-language/vocabulary.md)。
