# 节奏

节奏不是信息的排列，是时间的呼吸。沉默和停顿也是节奏。本文件是**单拍时长上限 / 认知负荷 CL / 通道堆叠上限**三个量化指标的全仓唯一来源；10 条节奏曲线的完整定义与曲线适配见 [`curves.md`](curves.md)。

## 量化指标（唯一来源）

| 指标 | 值 | 含义 |
| --- | --- | --- |
| **单拍时长上限** | 含角色拍 ≤6s；纯视觉拍 ≤8s；钩子拍（B1）不受限 | 超上限角色一致性显著下降。超上限 → 拆子拍，子拍共享父拍的角色与不变量 |
| **认知负荷 CL** | 目标 1.5–2.0 | 单拍要让观众认多少东西。倒 U：过低平淡，过高工作记忆过载 |
| **通道堆叠上限** | ≤2 | 同一拍同时承载的信息通道数（画面/口播/字幕/音效）。堆叠 3 条以上需显式标注理由，且不得持续 |

`rhythm_intensity = (ID + ED + CL + CF) / 4`（信息密度 ID · 情绪密度 ED · 通道堆叠 CF）。CF 是单边约束：`CF<2`——同一拍不叠加两路以上的高频变化。

**护栏**：无连续 5s 平均镜头长度 <1.8s；CF 达 5 不持续 ≥3s，须插 ≥1s 停顿；关键信息放在 0.66s 窗口内，V≥4 时延至 ~1.2s。

## 节奏曲线

10 条曲线定义时间维度的变化形状（匀速/压缩-释放/渐进加速/渐进减速/呼吸脉冲/空白即节拍/断裂/渐入渐出/复节奏/顿音）。选择时即考虑**第二遍是否成立**——压缩-释放/顿音/呼吸脉冲天然适合重播。

结构与适配规则见 [`curves.md`](curves.md)。映射模式（同频/半速/倍速/反拍/对位/混沌）定义音画关系：>15s 同模式切换一次。

## 停顿点

停顿不是故障。三段式：**前状态 → 间隔 → 后状态**。CF≥4 的段每个边界后需 ≥1s 停顿，否则工作记忆过载。

| 位置 | 类型 | 时长 | 镜头行为 |
| --- | --- | --- | --- |
| 关键信息/复杂画面后 | 消化性沉默 | 0.5-2s | 静态 hold + 极微 push-in，镜头几乎不动 |
| 修辞问句后 | 预期性沉默 | 1-2s | rack focus 或 slow pull-back |
| 高潮前/反转前 | 悬念沉默 | 0.3-1s | 静态 + 心跳节奏微晃 |
| 跨场景切换 | 场景边界 | 1-2s | 全景拉远 → 停顿 → 推入新场景 |
| 笑点/爆点后 | 落地 | 0.5-2s | 定格或静帧 hold |
| 能量段间 | 呼吸字卡 | 1.5-2s | 静态标题卡，镜头完全静止无微运动 |
| 收尾 | 余韵 | 0.3-2s | slow pull-back 或渐暗 |

执行格式：`T1：B0 后 0.3s 预期性沉默 | 間：送达→默想→下个信息 | 视觉：定格(0.3s) | 音频：瞬寂`。镜头行为指 [`../shot-language/SKILL.md`](../shot-language/SKILL.md) 的运镜与景别。

## 节奏-运镜耦合

节奏强度同时决定切频与镜头语言（运镜词汇见 shot-language）：

| rhythm_intensity | 推荐运镜 | 推荐景别 | 切频 |
| --- | --- | --- | --- |
| 高强 (4-5) | handheld / whip pan / fast push-in / quick tilt | CU/MCU 为主，偶用 ECU | 0.5-1.5s |
| 中强 (3-3.9) | dolly-in/out / stable tracking / slight orbit / slow pan | MS+MCU 交替 | 2-4s |
| 中低 (2-2.9) | slow push-in / static + micro movement / slow tilt | MS 为主，偶用 WS | 4-8s |
| 低强 (1-1.9) | static locked / extremely slow dolly / wide hold | WS+MS 为主 | 8s+ |

**Adams 双因子**：节奏感知 = 镜头时长 × 运动量。两者互补——长拍+高运动，短拍+低运动，都得到中强节奏感。设计时权衡两因子，不只看切频。

## 音画节拍映射

音频起止与视觉转场偏差 **≤0.3s**（锚点拍 ≤0.1s）。三层次（环境基底 / 叙事标记 / 情绪曲线）是设计语义：PAD 1-3 = 环境基底+轻音；PAD 4-5 = 音乐主题变奏突显；D 骤降 = 瞬寂或基底抽离。

## 例子

输入（骨架表两行 + 渠道参数）：

> 60s 抖音竖屏，钩子前 3s；拍 2「鲸鱼娘端白米饭上高台」4s；拍 3「Astra 娘只说一句话，全村活自动排队」4s。

输出（节奏）：

> 曲线：压缩-释放（拍 2 蓄力 → 拍 3 释放）。拍 2 时长 4s（含角色，≤上限 ✓），CL 1.8，通道堆叠 1（画面），拍末 0.5s 消化性沉默（静态 hold + 极微 push-in）。拍 3 时长 4s，CL 1.7，通道堆叠 2（画面 + 口播，显式标注：台词即笑点），rhythm_intensity 3.4 → dolly-in + MS/MCU 交替，切频 3s。钩子拍 1 时长 3s（B1 不受单拍上限约束）。
