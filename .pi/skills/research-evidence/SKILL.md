# research-evidence

研究阶段的唯一方法源。一条链：断言 → 证据 → 判定 → 措辞强度。产出是**证据锚点表**，供 narrative-architect 搭骨架、writer 与 video-director 写作时引用。

## 五条研究信条

1. **证据锚定胜于叙事优雅** —— 可验证是第一优先级。
2. **诚实标注不确定性** —— 「不可验证」不等于「证伪」。
3. **谱系独立决定证据强度** —— 同一来源转载、同一团队、互相复引的两条，算一条证据。
4. **引用存在不等于引用有效** —— 须经结构验证与溯源核对。
5. **具体的人是你的最终读者** —— 「判定」行的意义是让下游一次读清，不用追问。

## 流程

### 1 第一性还原

把选题拆成 2-3 条不可再分断言。含价值判断的退回。拆不出 = 「这是雾，无法研究」。

**结构幻觉自检**：断言之间的因果链若不能从源材料追溯，标「结构幻觉风险」。

### 2 证据契约

每条证据必须满足：

- 绑定到一条具体的原子子断言，一证据一断言。
- **显式引述源文本 + 定位标识符**（段落号 / 行号 / 时间戳）。不接受转述——转述无法被核对。
- 拒收：无关背景、无数据的观点文、不可验证的二手转述。

### 3 结构验证（先于一切语义判断）

引用输出前检查 **URL 可访问 + 正文包含所引述文本**。打不开或引述对不上 → 不得作为「可引用为事实」输出。默认状态是「嫌疑」。

这是**自反防护**：研究岗位自身也会产出不存在的引用，而一处幽灵引用会被后续复引放大成级联污染。结构验证是硬前置，不是可选项。

### 4 语义验证

对每条（证据, 断言）：正向问「这段文本是否支持该断言」→ 再用相反提示问「是否反驳该断言」→ 比对。两次结论矛盾 = 验证者自判不稳定，标「自一致冲突」并降一级。

### 5 事实性 / 忠实性分离

两个维度分别标注，合称 FRANQ 判定：

- **事实性** —— 断言本身是否正确，需外部知识核对。
- **忠实性** —— 断言是否忠于被引来源，需引述文本比对。

**事实正确但不忠实** → 标「事实正确，对来源不忠实」并降级；此类不得用于核心论点（可用来展示反差）。

### 6 引用类型、谱系与级联污染

- **引用类型**：Q 引述 / C 压缩 / I 推理。推理鸿沟最大，I 类最易失真。
- **谱系**：同出一次通稿、同一团队、互相复引 = 同一谱系。同谱系多篇不算多条证据。
- **级联污染**：来源自身引用了不存在的文献，或引用链超过 2 跳 → 标「级联污染：低 / 中 / 高」。

### 7 门禁

- 每个信息点 ≥1 条跨谱系证据；做不到 → 诚实标注「**仅单谱系来源，置信度受限**」，不得省略标注。
- 超过 1 年的单一来源不可作唯一支撑。
- **反证扫描**（不可跳过）：用 ≥2 种搜索模板主动找矛盾来源。找到同等强度的竞争证据 → 标「竞争证据：未解决」并给出双解释。
- **未支撑扫描**：无法直接追溯到锚定证据的断言占比 >20% → 整体置信度降一级。

### 8 措辞强度

措辞强度分三级（三级措辞）：

| 强度 | 措辞 | 条件 |
| --- | --- | --- |
| 3 | 表明 | 多源独立交叉验证 + 含具体数字 + 引用影响力已核对 |
| 2 | 与…一致 | 多源共享谱系；或单一来源但有方法学研究支撑 |
| 1 | 暗示 | 单一来源 / 谱系不独立 / 引用影响力未核对 |

**谱系不独立封顶在 1**。跨谱系要求没满足时，措辞不得升到 2。

## 产出：证据锚点表

每个信息点一条证据块，字段固定：

| 字段 | 取值 |
| --- | --- |
| 判定 | 可引用为事实 / 须注明来源 / 不可引用（下游第一眼读的字段） |
| 事实性 | ✓ / ✗ / 不可判 |
| 忠实性 | ✓ / ✗ / 不可判 |
| 谱系 | 独立 / 同谱系 / 不确定 · 引用类型 Q/C/I · 级联污染 低/中/高 |
| 关键引用 | 显式引述 + 定位标识符（缺此字段即不合格） |
| 措辞 | 暗示 / 与…一致 / 表明 |

## 真例

**输入**：一条考据命题——「血锁一护的官方形态是什么」。检索到电击在线 85246（Aniplex 通稿转载，2026-08-23）与两张 CDN 原图。

**输出**：证据锚点表的一行。

| 字段 | 值 |
| --- | --- |
| 信息点 | 血锁一护 = 半虚化后卍解，双角，颈/手/足迸发血锁灵压 |
| 判定 | 须注明来源 |
| 事实性 / 忠实性 | ✓ / ✓ |
| 谱系 | 单谱系（通稿原件与转载页同源）· 引用类型 Q · 级联污染 低 |
| 关键引用 | 「首・手・足には血鎖の霊圧が迸る」（85246 §1.1） |
| 措辞 | 暗示（**仅单谱系来源，置信度受限**） |

判定给「须注明来源」而不是「可引用为事实」：来源是官方一手，但通稿与转载页同属一个谱系，反证扫描无独立对象。下游写这条时必须带限定词。
