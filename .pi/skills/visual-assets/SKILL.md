# visual-assets — 视觉资产规范

视觉资产让一个论点可以被眼睛识别，不是给文章配图。每张图服务某个关键信息点。

## 一图一论点（判据）

**说不清这张图支撑哪号关键信息点 → 不画。** 两关键点有不可分割的因果关系时，才可合并为一张因果图。

## 参考资产比例铁律

参考资产的比例由资产自身的内容结构决定，**不由最终产出格式决定**。成品是 9:16 竖屏，不改变参考图的画幅：多视图合成帧按 16:9 或 3:2 存档（短边 ≥1024px），不裁成成品比例。分镜关键帧是例外——它是最终帧的预览，比例与输出一致。

## `.svg` 单源与命名

- 图以单文件 `.svg` 为源，存选题 `assets/`；正文只在 `<!-- fig:N -->` 标记处引用 `![figN-slug](<相对路径>)`，**不复制**到别处。
- 命名 `figN-<slug>.svg`，N 对应关键信息点序号；渐进揭示图加层号后缀 `-l1` / `-l2`。
- 每个 `.svg` 带 `<title>`（`<svg>` 直接子元素）+ 复杂图的 `<desc>` + `role="img"` + `aria-labelledby`。
- 视频分镜关键帧的命名与登记遵循 [`.pi/skills/asset-search/SKILL.md`](../asset-search/SKILL.md) 引用的资产库规范（`assets/asset-lab.md` + `assets/taxonomy-registry.md`），本 skill 不另立命名规则。

## 渠道约束：只引用，不定义

组块上限、字数/时长、钩子位置一律读 [`.pi/skills/channels/CHANNELS.md`](../channels/CHANNELS.md) 与对应渠道卡。本 skill 只定义视觉特有的呈现约束：

- 读者约束（渠道组块上限、注意状态）是全部构图决策的上限。
- 最小字号：缩略图场景（组块上限 ≤5）≥16px，正文/详情场景 ≥14px，视频帧 ≥24px。
- 视觉复杂性：TiR 0.15-0.35，细节深度 MeC ≤ 组块数 × 30%。
- 边缘安全区（视频关键帧）：元素落在左右 ≥10%、上下 ≥8% 内，防生成边缘裁剪；文章用 `.svg` 不受此约束。

## 构图（始终从论点出发）

1. **论证类型定布局**：对照 / 序列 / 层级 / 否定 / 因果 / 网络 / 时间线 / 象限。
2. **证据按感知精确度编码**：位置 > 长度 > 角度 > 面积 > 体积 > 色饱和度 > 色调（Cleveland & McGill 1984）。
3. **空间关系承载论证**：对齐 = 关联，嵌套 = 包含，箭头 = 因果，叉盖 = 否定。
4. **强调色只用一处**；需区分 ≥3 语义类别时用 3-5 色语义调色板，且每色对应不同形状/位置冗余编码。

## 视觉底线

- 低噪音高信息密度：白底、黑线、最多一个强调色；去掉网格/阴影/渐变/装饰边框。
- 视觉层级 > 视觉元素：大小、粗细、深浅、留白决定读者先看什么、后看什么。
- 色觉安全：不靠单一颜色承载语义（约 8% 男性有色觉障碍），形状/位置/文字冗余。
- CJK 文字宽约拉丁文 1.5-2 倍：标注框宽度 = max(160, CJK 字符数 × 18)。

## 生成与验证

手绘风为主（roughness=1.2-1.5）；架构图与精确数据对比用直线精确风格（roughness=0）。**禁止 matplotlib。** 生成后过渲染验证，四条不可省：

1. 结构——SVG 可解析、viewBox 存在、标签闭合。
2. 目验——导出 PNG 查文字裁剪/溢出、箭头跨区混乱、CJK 完整。
3. 比例——关键量级的视觉比例与数据一致。
4. 优化——svgo 压缩，移除冗余元数据。

## 参考素材去重

下载或生成任何资产前，先在 `assets/` 现有索引查重，命中即复用，不重复生产。来源、来源性质、验证状态写进来源清单。

## 反模式护栏

| 反模式 | 表现 | 预防 |
| --- | --- | --- |
| 箭头乱麻 | 跨区连线交叉缠绕，流向不可追 | 跨区连线 ≤3 条；层次布局 + 路由避直线穿透 |
| 文字溢出 | CJK 超出容器边界 | 框宽 = CJK 字符数 × 18 + padding |
| 比例失真 | 视觉面积与数据量级不符 | 面积/长度与数据成比例，完成后量尺验证 |
| 数据幻觉 | 图中数据与证据源不一致 | 生成前建数据-视觉对照表，生成后逐项验证 |
| 语义丢失 | SVG 无标签语义，工具链无法恢复结构 | 分组加 data-role，保留 title/desc/aria |

## 例子

真实输入：一个视频选题的第 4 拍（记在人审表 `products/<id>-<slug>/review.md`）：画面「台下开源 NPC 少女排队上供，队伍看不到头」｜全景｜推。渠道 = 抖音。

真实输出（本 skill 规范的应用）：

- 一图一论点——支撑关键决策 3「世界观只由角色喜剧承载」：队伍长度 = 供给量。
- 论证类型 = 层级/结构；证据编码 = 长度。
- 分镜关键帧，比例与输出一致（9:16）；元素落在左右 ≥10%、上下 ≥8% 内。
- 产出 `STB_T006_AstraCult_Queue_B4_v01.png`，按资产库命名规范登记 `assets/storyboards-index.md`。

文本产出走 `.svg`：关键信息点 4 出图 → `products/<id>/assets/fig4-queue.svg`，正文在 `<!-- fig:4 -->` 处嵌入 `![fig4-queue](assets/fig4-queue.svg)`。
