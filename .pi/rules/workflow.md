# 流程阶段

内容生产是一条固定流程，末端按交付形态分叉。阶段定义见 [`system/PRODUCT.md`](../../system/PRODUCT.md)「流程骨架」——本文件只写约束，不复制定义。

- 阶段顺序固定，不可跳：研究 → 结构 → 创作 → 视觉 → 校验。
- 创作阶段才按交付形态分叉（文本 / 视频）；研究与结构阶段两种形态共用，不得各建一套。
- 视觉按交付形态并行，不单独成阶段。
- 每个阶段一个产出、一个人审点；上一阶段人审未过，不得进入下一阶段。
- 跨阶段返工只回到出问题的阶段，不重跑整条流程。
- 状态推进由 `scripts/` 的执行引擎管理，不手改状态或 frontmatter。

阶段产出与人审点的字段见 [`system/PRODUCT.md`](../../system/PRODUCT.md)「人审面」。
