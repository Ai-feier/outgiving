# Triage 标签

- 五个角色标签，标签字符串即角色名：不改写、不翻译、不新增同义标签。
- skill 或流程提到某个角色时，直接用本表的字符串落到 issue 上。

| 标签 | 含义 |
| --- | --- |
| `needs-triage` | 待维护者评估 |
| `needs-info` | 等报告者补信息 |
| `ready-for-agent` | 规格完整，可交 agent 执行 |
| `ready-for-human` | 需人来实现 |
| `wontfix` | 不做 |

操作命令见 [`issue-tracker.md`](issue-tracker.md)。
