# AGENTS.md — 决策记录

决策记录保存 AI harness 的长期决策、取舍与落选方案。约定（布局、生命周期、格式）见 [README.md](README.md)；本文件只是入口。

写之前：

1. 先看边界：产品事实与结构进 `system/`，约束进 `.pi/rules/`，方法进 `.pi/skills/`（见 README「边界」）。
2. 搜 `proposed/` 与 `implemented/` 是否已有文件拥有该决策。完全取代 → 更新或归档旧文件并交叉引用；部分取代 → 两者都留并交叉引用。
3. 严格按 README 的格式写：三行头部、对应生命周期骨架、必写的 `## 被否方案`。
4. 核对每条相对链接可解析。本目录没有检查门。
