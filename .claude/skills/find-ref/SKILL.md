# find-ref — 参考素材搜索 Skill

为任何 agent 提供标准化流程来寻找参考素材。不是替代专业判断，是确保搜索有据可查、可复现、可精进。

## 与现有系统的关系

| 系统 | 本 skill 的角色 |
|------|----------------|
| visual-designer 角色参考图流程 | 第 2 步"网上找"的标准化执行者 |
| visual-designer 生图确认门（`gates/image-gen-*.md`） | 产出作为 gate 的「参考图声明」输入 |
| `assets/` 资产系统 | 素材先存 `ref-images/`（按主题子目录），经验证后晋升 |
| gather-expert 研究流程 | 互补 — gather-expert 搜文本证据，本 skill 搜视觉/听觉素材 |

## 五步法

搜索必须走完五步，每步产出作为下一步输入。

### 第一步：明确需求

| 问题 | 选项 |
|------|------|
| **类型** | 图片 / 视频 / 音频 / 3D模型 / 设计参照 |
| **用途** | 身份锚定 / 场景定调 / 动作参考 / 风格参考 / 情绪锚定 / 材质参考 |
| **预期数量** | 设定图 1-3 张 / 截图 3-5 张 / 模型 1-2 个 / 音频 1 段 |
| **质量门槛** | 分辨率≥1024px / 音频≥128kbps / 视频≥720p |

**产出**：一行需求声明，如 `需求：T003「林北」角色身份锚定，1-3 张设定集级（多视图/中性表情/纯色背景），≥1024px。`

**约束**：身份锚定→只搜角色设计稿；场景定调→搜全景+关键角度；动作参考→搜多帧/视频。

### 第二步：来源策略

按优先级分级搜索。**从 P0 开始，命中即停**。

```
P0 — 官方来源（官网/官推/设定集/官方壁纸/授权合作）
P1 — 动画截图（fandom wiki / 截图站点 / 帧序列提取）
P2 — 游戏资源（Spriters Resource / models-resource）
P3 — 同人/艺术站（DeviantArt / Pixiv / Danbooru）
P4 — 3D模型站（Cults3D / Sketchfab / Thingiverse）
P5 — AI 生成 fallback（仅 P0-P4 均无可用时）
```

**每级关键词策略**（多语言+多措辞，≥3 种组合命中即停）：

```
# WebSearch 用以下模板，命中后 WebFetch 提取具体 URL
中文: "{角色} 设定图" "{角色} 角色设计" "{IP} 画集"
英文: "{char} character design sheet" "{char} concept art" "{IP} artbook"
日文: "{キャラ} 設定画" "{キャラ} キャラデザイン" "{作品} イラスト集"
```

P0 官方搜索：`WebSearch "{IP} official website character art"` / `"{IP} art book scan {char}"` / `"{IP} key visual"`。
P1 截图搜索：`WebSearch "{IP} wiki gallery {char}"` / `"{char} screenshot {episode}"` / `"{char} {action} gif"`。
P3 优先搜 Pixiv/Danbooru 标签系统。

### 第三步：搜索执行

**规则**：每级搜 ≥3 种关键词组合 → 均无结果才降级 → 记录每次搜索的来源 URL（命中与否都记）。

**搜索执行日志格式**（每次搜索后追加）：
```
## 搜索日志 — {日期}
需求：{需求声明}
| 优先级 | 关键词 | 站点 | 命中? | URL |
|--------|--------|------|-------|-----|
| P0 | {keyword} | {site} | Y/N | {url} |
最佳结果：{命中的最佳素材} / 未命中原因：{...}
下一步：继续搜索 / 降级 / 切换 fallback
```

### 第四步：素材验证

素材必须通过以下检查才能下载。**验证不通过 → 回第三步**。

| 检查 | 判定 |
|------|------|
| 分辨率≥1024px（设定图）/≥512px（截图） | 通过/不通过 |
| 无压缩伪影/水印（如有→标注"带水印"，不用于规范参考） | 通过/不通过 |
| 主体完整可见 | 通过/不通过 |
| 用途匹配（身份锚定→中性表情/服装可辨；场景→全景/光照可识；动作→多帧/视频） | 通过/不通过 |
| 来源站无明确「禁止转载/禁止商用」声明 | 通过/不通过 |
| 标有其商标/LOGO → 标注「参考用途，不用于发布」 | 通过/不通过 |

**P5 AI 生成素材** → 标注「AI生成，仅风格/构图参考，不可直接使用」。

### 第五步：下载和引用

#### 命名规范

素材下载到 `ref-images/{TopicID}/`，格式：`{SEQ}_{Type}_{Purpose}_{Entity}_v{NN}.{ext}`

| 段 | 规则 | 示例 |
|----|------|------|
| SEQ | 三位数字 | `001` |
| Type | `char`/`scene`/`prop`/`style`/`action`/`audio`/`ref` | `char` |
| Purpose | `identity`/`mood`/`motion`/`look` | `identity` |
| Entity | PascalCase | `LinBei` |
| Version | v两位 | `v01` |

示例：`001_char_identity_LinBei_v01.png`

#### 来源清单（ref-sources.md）

每批搜索在 `ref-images/{TopicID}/ref-sources.md` 记录：

```
| 文件 | 类型 | 用途 | URL | 来源性质 | 版权状态 | 验证状态 |
|------|------|------|-----|---------|---------|---------|
| 001_char_identity_LinBei_v01.png | 角色 | 身份 | {url} | 设定集扫描 | 个人参考 | 已直接验证 |

来源性质：官方设定集/动画截图/游戏资源/同人/模型站/AI生成
版权状态：个人参考用途（默认）/仅内部使用/可商用
验证状态：已直接验证/未独立验证/推测
```

#### gate 对接

素材清单作为 visual-designer「生图确认门」的参考图声明输入：

```
参考图声明（find-ref 产出）：
  正参考：ref-images/T003/001_char_identity_LinBei_v01.png（官方设定集，身份+脸型+发型+服装）
  负参考：ref-images/T003/003_style_look_WrongStyle_v01.png（风格不匹配当前选题）
```

gate 文件写入 `gates/image-gen-{资产名}.md`。

## 精进机制

每次使用后，追加到 `.claude/skills/find-ref/refinement-log.md`：

```
## 精进 #{N} — {日期}
需求：{需求声明} | 命中：Y/N
有效策略：{关键词/来源 → 命中 P0，优先使用}
无效策略：{关键词 → 无关/低质，下次跳过}
优先级建议：P{X} 的 {来源} 应交换
本 skill 优化：{新增/修改的方法或来源站点}
```

**触发条件**：连续 2 次 P0-P4 全未命中 / 来源站点失效 / 发现新站点 / 用户反馈搜索质量差。

**原则（减法优先）**：加关键词是最低优先级。先确认已有策略被完整执行，执行了但无效才有理由新增。

## 禁止清单

- 不下载有明确「禁止转载/禁止商用」声明的素材
- 不下载需登录/付费墙的素材
- 不直接将素材用于发布内容（仅作为 AI 生成参考）
- 不复制素材到平台发布目录（保持在 `ref-images/`）
- 不对素材做修改后作为自己的作品发布

## 质量门禁

```
□ 五步流程全部走完
□ 素材已按命名规范存入 ref-images/{TopicID}/
□ ref-sources.md 已生成，每项来源 URL 可访问
□ 所有素材通过质量+版权检查
□ gate 对接的参考图声明段落已准备
□ 搜索执行日志已更新（含未命中记录）
□ 精进日志已更新（有效/无效策略）
```
