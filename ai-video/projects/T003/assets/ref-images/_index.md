# _index — 参考图清单

> LLM 可读。每行 = 一张图。`grep "关键词" _index.md` 快速定位。
> 新增图片时追加一行。晋升 `assets/` 后移除对应行。

## 字段

| 字段 | 含义                                                                                             |
| ---- | ------------------------------------------------------------------------------------------------ |
| ID   | 文件名 + 缩略图预览                                                                              |
| T    | 类型：CHR角色 / SCN场景 / KV官方视觉 / LYT布局模板                                               |
| 内容 | 角色名或场景名                                                                                   |
| 视角 | front/3:4/full/sheet(多视图)/wide/close                                                          |
| 用途 | id(身份锚定)/outfit(服装)/color(配色)/scene(场景定调)/layout(布局参考)/style(风格)/neg(负面参考) |
| 源   | web来源域名 或 "ai:Seedream"                                                                     |
| 质量 | 分辨率短边px / 清晰度(H/M/L) / 遮挡(Y/N)                                                         |
| 描述 | 一行摘要                                                                                         |
