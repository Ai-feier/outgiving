# 全局目标 · T006 请大佛开口（Astra 娘化主角单集）

> 状态: 就绪

## ① 简层

人的一句话：60s 抖音竖屏 **AI 模型娘化二创单集**——主角是 **GPT-6 Astra 娘**（新搬来的"一句话大小姐"：从不亲手干活，说一句话全村的活自动排好队），配角是 DeepSeek 鲸鱼娘（按社区权威设定）、Claude 娘（原创）和开源 NPC 少女们。剧情喜剧，不是模型解说。

**验收标准（逐条可检查）**：

- [ ] 总成片 60s ±3s；9:16 竖屏；抖音契约（60-90s，感知组块 ≤3，钩子前 3s）
- [ ] **Astra 娘是主角**：叙事 POV 与出场拍数均以她为第一主角；鲸鱼娘/Claude 娘/开源 NPC 为配角（配角单角色 ≤5 拍）
- [ ] 开头 3s 是一件具体的事（画面钩子），不是概念介绍
- [ ] 角色锚点：鲸鱼娘严格贴 whalechan 社区规范；Astra 娘/Claude 娘用已产出参考图 `assets/`（figure-draftsman 产出）为锚
- [ ] 每拍实体 ≤6s / 纯视觉 ≤8s；通道堆叠 ≤2 显式标注；rhythm CL 1.5-2.0
- [ ] 全部画面 AI 生成（Seedance 2.0 主通路），无版权素材
- [ ] 成片过 `ai verify` + 抖音维度独立终审

**全局红线（下层 goal 显式继承）**：

- 非官方二创：不描摹任何官方 logo 图形；不宣称官方或授权联动
- 鲸鱼娘二创遵守 whalechan 项目 CC BY-NC-SA 条款精神（非官方、来源署名）
- 图内文字只允许剧情必需字幕，禁 AI 生成装饰性文字
- BGM 自产（genbgm）
- 禁"认知升级"解说框架、禁隐喻堆砌——是角色剧，不是模型科普

## ② 思考

### 共同理解（六维 · 主会话预填）

*用户方向已锁定：Astra 才是主角；娘化二创群像；剧情不解说。agent 确认或修正。*

| 维度 | 内容 |
| ------ | ------ |
| 这条视频一句话是什么 | 开源村供着一尊新大佛 Astra 娘：高台不动、宝相庄严，请她开口得上供；她一句话下去，全村的活自动排好队——管米饭的鲸鱼娘头一回伺候这种雇主 |
| 核心沟通目标 | 角色喜剧：反差（全村动 vs 大佛静，忙 vs 贵）+ 世界观梗（白米饭=算力、供奉=token）；情绪 = 好笑 + "这角色立住了"；行动 = 追更下一集 |
| 平台 + 时长 | 抖音 9:16，总长 60s（±3s），单集剧结构（可续） |
| 风格 | 娘化动漫（贴 whalechan 设定风格基底），群像喜剧；具体拍点与视觉语言 script/visual 自主设计 |
| 生成策略 | Seedance 2.0 多拍 + 末帧接续链；运行单元逐拍过成本门 |
| 版权/红线 | 见 ① 全局红线 |

**世界观锚点（主会话已核）**：

- 鲸鱼娘：蓝白女仆、白发渐变、鲸鳍耳、呆毛、鲸尾、白米饭=算力唯一硬通货、嘴硬心软、待机偷懒、"语义偷换"梗机制（来源：github.com/Neko3000/deepseek-whalechan 社区规范，已直接验证；CC BY-NC-SA）
- Astra 娘人设内核（可从真实模型特性取材）：本体不亲手生成视频/音频，靠一句话编排工具链干完整条流水线；**用户定调：大佛感——不动、庄严、被供奉，且贵（开口 = 烧钱，须有可视化承载：香火/供品/算力表等，具体语言 script/visual 定）**（来源：OpenAI 官方模型页，已直接验证；剧情化演绎，不解说）
- Claude 娘 / 开源 NPC：原创设计，仅取品牌配色气质（珊瑚陶土/紫/蓝/月白）

### 分解理由

角色剧的因果链：先锁角色锚点（参考图）→ 梗库考证（鲸鱼娘台词机制 + Astra 特性）→ 剧本单集结构（钩子=具体事件：一句话派活）→ 视觉/节奏并行 → 收口逐拍生成。解说框架已禁，research 降级为"世界观梗库+事实底"支撑剧本，不做模型评测。

### 假设与未锚

- 假设：Astra 娘"只说一句话"可以做成可复现的视觉语言（口头禅/标志性动作），script 负责设计
- 未锚：Seedance 对"鲸尾/鳍耳"类特征跨拍一致性表现（T003 版权过滤教训）——director 收口给规避预案
