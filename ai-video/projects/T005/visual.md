## ③ 内容详情

#### 1. 视觉形态

**纯视觉变身奇观（Bleach 最终章质感，16:9 横屏 2×5s）**。非叙事——不讲故事，雕刻一次呼吸：被囚（压抑）→ 破锁（觉醒）→ 刀横置（蓄满）→ 睁眼（点燃）→ 轰穿（释放）。零信息负担，全情绪。

视觉取舍：

- **奇观优先**（~85%）——形态揭示（双角+黑半虚化面具+血锁灵压）+ 王虚式闪光爆发（黑红 Cero 洪流轰穿镜头）
- **情绪落点**（~15%）——1C 末 1.8s 落定静帧 + 2A 静帧 1.0s：时间停滞的一拍，让观众「看到力量被装满」

**单生成单元单镜头**：每个 5s 段是一个连续镜头（AI 视角无硬切；子拍 1A/1B/1C、2A/2B/2C 是设计标注的三段/四段时序推进，非剪辑点——这是 M6 门 3 关注项的核心）。

**判定**：P0 = 形态身份锚点（双角/面具/血锁/刀/配色五特征）+ 末帧稳定性（居中/全入画/光照稳定/无运动模糊）。背景为抽象墨韵虚空，无场景身份问题。

#### 2. 六维视觉构建

##### [镜头] — 焦距承载心理距离（16:9；H3=768p横，Seedance=16:9）

| 子拍 | 景别（等效焦距） | 心理距离 |
| ------ | ---------------- | --------- |
| 1A 压抑 | medium 全身（~50mm），角色占幅 ~1/2 | 被压——与角色同高偏低，仰视其被压的姿态 |
| 1B 觉醒 | medium→MWS（50mm→35mm，空间张开） | 挣脱——空间随锁断张开 |
| 1C 锁定 | medium/MWS（~50mm），全身+双角+刀全入画 | 威压——力量正面对观者，规范参考帧 |
| 2A 点燃 | ECU 面具眼区（~85mm）→极缓 pull-out 至 MWS | 窥视→平等——力量已转到观者侧 |
| 2B 突进 | MWS→medium（角色冲向镜头、占幅增大） | 冲势——距离坍缩 |
| 2C 释放 | 光束充满画幅（焦距让位于 Cero） | 零距离——被自己的释放吞没 |

**禁止**：鱼眼、微距、变焦 push/pull（破坏 Bleach 静止蓄力感）。

##### [运镜] — 静止为主，爆发式运动（语汇 ≤3 种）

| 类型 | 用途 | 子拍 |
| ------ | ------ | ------ |
| 静态 + 几不可察的 push-in | 压抑 hold、蓄满落定——止め絵核心 | 1A、1C 末 1.8s |
| 手持微漂移 + push-in（加速） | 觉醒过程——空间开始不安 | 1B |
| rapid push-in / tracking + 角度 low→eye-level | 突进——向镜头冲来 | 2B |
| static + 微 recoil | Cero 轰击瞬间镜头微震 | 2C |

**禁止项（日系 [STYLE-DEP]）**：快速旋转 / whip pan / complex tracking / crane shot。单变量原则：每个子拍只动一个运镜变量。

##### [布光] — 情绪优先：血红自发光 = 唯一光源

无物理光源逻辑——墨韵虚空无太阳无灯。布光服务于「哪种情绪需要被看到」。

- **主光 = 自发光血红灵压**（锁链/眼/Cero）。1A：锁链处微弱明灭（被囚状态）；1B：迸裂时增强；1C：全发但**稳定不闪**（P0 末帧约束）；2A：眼区辉光为主光；2B：链+速度线光；2C：Cero = 全片最亮自发光，吞没一切。
- **补光**：无（黑底 void）。
- **轮廓光（rim）**：血红，宽 1-3px——使角色从纯黑中「浮出来」（本世界 rim 是血红而非 Bleach 通用的冷白，因全片唯一暖源是血锁）。
- **阴影**：暗部压至 5-15% 亮度，色相偏移深蓝黑（#0D0D14 系，非灰）。
- **光影交互**：焦散——锁链辉光在皮肤/刀身上投出血色光斑；次表面散射（SSS）——锁点处皮下透光（1A 的「搏动」即皮下光透）；体积光——Cero 洪流中的墨雾被照亮。
- **闪烁规则（P0）**：链辉明灭只允许出现在 1A（压抑）与 1B（迸裂）；**1C 起辉光稳定、零频闪**（末帧光照稳定 + Seg2 段接续要求）。

##### [色彩与材质] — 三色法（基色+阴影色+高光色），每材质类独立

| 材质类 | 基色 | 阴影色 | 高光色 | 备注 |
| -------- | ------ | -------- | -------- | ------ |
| 墨韵虚空（背景） | 近黑 #0A0A0E | 深墨 #050508 | 墨灰 #2A2A33（触须边缘） | 无地面无墙 |
| 橙发（不变基底） | 高饱和橙 #E8760B | 褐橙 #8A4800 | 亮橙 #FF9829（发束顶面色带） | 全形态保留——身份锚 |
| 黑死神装束（不变基底） | 哑黑 #1A1A24 | 深蓝黑 #0D0D14 | 冷灰 #8A8A9E（1C 起链辉映红边） | 褶皱锐利 |
| 黑半虚化面具 | 哑黑 #141418（**黑，非白**） | 近黑 #08080A | 血红 #C41E2A（能量沿线） [OQ-2] | 半虚化≠完全虚化 |
| 血锁锁链灵压 | 血红 #C41E2A | 深红 #6A0E14 | 亮红 #FF3040（发光边） | 颈/手/脚，自发光 |
| 卍解刀（形变后） | 银黑 #2E2E3A（默认，[OQ-4]） | 黑 #0D0D14 | 血红 #C41E2A（刃缘能量） | 刀随形变 |
| Cero 洪流 | 黑红复合（默认黑心红缘，[OQ-9]） | 黑 #0A0A0E | 亮红 #FF3040 | 自发光峰值 |
| 速度线 | 墨灰 #2A2A33 → 血红（2B 拉满） | — | 白点（线端） | 密度=速度 |

**全局色调**：黑底 + 血红高光 + 橙发（唯一非红暖色，身份辨识）。**禁止色**：全白面具、粉色/糖果色、高饱和绿、暖黄/sepia 滤镜、大面积灰中间调。

##### [构图] — 剪影优先 + 负空间 + 安全边界

| 原则 | 规则 | 子拍 |
| ------ | ------ | ------ |
| 负空间 | 角色小而居中于黑 void——用空表达力量差与孤绝 | 1A（被四方墨韵压下）、1C |
| 中心对称 | 蓄满锁定帧——力量正面对观者 | 1C（**末帧必须居中**，P0） |
| 视线路径 | 角色目线：低垂（1A）→抬起（1C）→平视观者（2A）→消失于 Cero（2C） | 全程 |
| 对称→坍缩 | 2B 起对称被突进打破——角色冲向镜头 | 2B/2C |
| 安全边界 | 角色+双角+刀保持在 左右≥10%、上下≥8% 边界内（防 AI 视频边缘裁剪）；1C 末帧双角/面具/横置刀**全入画** | 全片，末帧 P0 |

**禁止**：对角线构图（削弱剪影辨识度）、多焦点（单帧焦点 ≤1）、2C 的 Cero 起点藏在角色身后（须正面冲向镜头，M3 正向约束）。

##### [景深] — 动画ぼかし（非物理镜头 DOF）

| 类型 | 用途 | 子拍 |
| ------ | ------ | ------ |
| 深焦（默认） | void 无物理远近——前景角色与背景墨韵均清晰（director style 行 `deep focus` 一致） | 1A–2B |
| 空气透视 | 远处墨韵触须 饱和度 -30% + 黑底淡出 | 全片（远端触须） |
| 径向模糊（放射ボケ） | Cero 爆发——中心清晰、向外放射模糊 | 2C |
| 运动模糊 | 仅 2B 突进的环境层（角色本体保持 sharp——「其形 sharp、其境 blur」） | 2B |

**禁止**：物理镜头色散/暗角/畸变；1C 静帧段的任何焦点变化。

##### V 值（visual 独立管理）

- **V=2 基线**（1 主体 + 抽象 void 背景 + ~5 材质类）：1A、1C、2A、2C（2C 的「画幅吞没」是材质层负载，非元素密度）。
- **V=3 尖峰**（元素密度 spike：速度线拉满 + 锁链迸裂 + 刀辉同屏）：1B、2B。
- CF 归 rhythm（<2 单边约束）；V 不再与 CF 做乘积约束。

#### 3. 情绪动作化 + 角色语言

> 本片中角色大部分时间面部被橙发/黑面具遮蔽——**身体通道是第一情绪通道**，面部微表情退居次级（仅 2A 睁眼与 1B 面具下的边缘可读）。抽象情绪词不进 prompt，全部翻译为身体锚点。

##### 3.1 情绪 → 可执行身体锚点（逐子拍）

| 子拍 | 情绪（script） | 禁用的抽象词 | 可执行身体锚点 | 微动作/微表情 | 环境交互痕迹 |
| ------ | -------------- | ------------ | --------------- | -------------- | ------------- |
| 1A | 压抑/被囚 (2/5) | trapped, desperate | 深蹲蓄力下蹲（膝盖内收、重心下沉）、头低垂橙发垂落遮面、肩胛内夹、脊柱微弓；身体随呼吸**轻微**震颤（幅度 ≤2px 等效） | 呼吸：浅促胸式（可见起伏 ≤2%）；目光：被发遮，不可见 | 墨韵触须向角色收拢（环境在压）；链辉在**皮下**明灭（未出体） |
| 1B | 觉醒/挣脱 (3/5) | awakened, powerful | 锁链自颈/手/脚四向迸裂（爆发向量=离心）；身体自蹲→起（0.8s 内完成）；黑面具自面部快速蔓延；双角顶出头部；刀随卍解发光形变 | 肩：内夹→打开（0.4s）；下颌：收→抬 | 墨韵被迸裂的链辉撕开光缝；速度线起（线密度 = 30% 拉度） |
| 1C | 全力量/蓄满 (4/5) | charged, intense | 正手持式（sōshi）落定：刀横置身侧、双手交叠于刀柄、双脚与肩同宽、脊柱垂直、头抬起；**完全静止、蓄满** | 呼吸：深缓腹式（起伏几乎不可见——力量=呼吸变慢）；链辉：全发且**稳定** | 墨韵触须退至画幅边缘（被威压推开）；辉光在刀身/皮肤投焦散光斑 |
| 2A | 点燃/聚焦 (4/5) | ignited, focused | 正手持保持（续 1C 末帧姿态）；双眼睁开血红辉光（**M2 双可读写法**：光自面具眼区渗出/环绕——`light shines through and around the eye region of the mask`）；时间停滞一拍 | 链：搏动一次（单次脉冲，非连续闪）；瞳孔锁定镜头（平视） | 辉光向外一圈微扩（如水面涟漪，1 圈） |
| 2B | 爆发/速度 (5/5) | fast, explosive | 骤然向镜头突进：身体前倾 15°、刀在前导（刀尖指镜头）、后手收至腰侧；一步之内跨越景别（MWS→medium） | 速度线拉满（密度 100%）；墨韵向两侧飞掠 | 空气撕裂（线端白点）；速度=「消失→出现」的断续节奏，非连续运动 |
| 2C | 峰值/释放 (5/5) | ultimate, release | 释放自身——黑红 Cero 洪流自胸前/刀端迸发，正面冲向镜头；角色被自己的释放吞没（形态在能量中部分可见） | 眼辉并入 Cero（G3 转化）；身体轮廓只剩剪影 | 全画幅黑红吞没；末 0.5s hold 吞没帧 |

##### 3.2 爆发型 vs 压抑型

**血锁一护 = 压抑型蓄力 → 爆发型释放**（双相角色）：

- 蓄力相（1A/1C）：力量不通过动作显示——通过**周围环境的反应**显示（墨韵收拢/退开、链辉皮下搏动/稳定辉光）。绝对静止 = 绝对控制。
- 释放相（1B/2B/2C）：先有停止帧蓄力（1C 末 1.8s、2A 1.0s）→ 瞬时爆发（ゼロ帧过渡，无中间帧）。

##### 3.3 角色语言四元素（视觉 DNA）

| 元素 | 定义 |
| ------ | ------ |
| **Signature Gestures**（≤3，script 已注册） | G1 低头蓄力（1A 专属，触发=压抑态）；G2 刀横置正手持（1C 起持续，2B 升级为「刀在前导」）；G3 睁眼血光（2A 专属，2C 转化为 Cero）。跨拍一致：用同一标签 `[KESSA_Ichigo]` 贯穿；重复时变化幅度/速度，不变动作本体 |
| **Effort Profile**（Laban） | 1A：heavy+sustained+bound→**Wring**（张力内蓄、外不动）；1B：strong+sudden→**Slash**（爆发无过渡）；1C：direct+strong+bound→**Press**（带着重量移动/停住）；2B/2C：strong+sudden+direct→**Dash** 系冲势 |
| **Camera Relationship** | 力量揭示主角：MS-MWS、**low-angle 仰视（威压/崇高）**、static→slow push-in；2B 起角度 low→eye-level（力量已到观者侧）；2C static+recoil（镜头被轰击——观者=被轰对象）。全程无 high-angle（不削弱力量） |
| **Emotion Override（情绪个人化）** | 全力量/蓄满 → 非微笑非怒吼：绝对静止 + 头抬起 + 链辉稳定（压抑型峰值=静止）；压抑 → 非瘫软：蹲踞 + 遮面 + 被抑制的呼吸（被囚而非放弃）；释放 → 非嘶吼：睁眼 + 一步突进 + 被自己的光吞没 |

##### 3.4 角色间空间语言（proxemics）

单角色片——空间关系全部发生在「角色 ↔ 观者/镜头」：1A 公共距离（>360cm，被压的孤独）→ 1C 个人距离（力量正面相对）→ 2B/2C 距离坍缩至零（突进/轰穿）。距离变化 = 权力关系变化，观众通过距离读取「他离我多近」。
